Browse Modes replaces the single alphabetical list you normally see when opening a library with a grid of discovery tiles — each a different way in: Trending, Top Rated, Mood, Genres, Story Themes, Hidden Gems, Just Added, Random, and more. The first tile, All, is your original list exactly as it was.

Only Trending and Top Rated need this plugin. Every other tile is a plain sort or filter the server already serves — the plugin fetches the TMDb lists that power those two modes and keeps them cached so they load instantly.

The tile grid itself is part of the client (web or Android TV), not the plugin. See the project README for client install instructions.

Scheduled tasks: "Refresh TMDb discover lists" (every 4 hours), "Refresh snapshot source lists" (daily) and "Refresh studio item counts" (daily). All can be triggered manually from Dashboard → Scheduled Tasks.

TMDb API
Required for the Trending and Top Rated browse modes. Keys are free from themoviedb.org. Every other browse mode works without one.
TMDb returns 20 titles per page and most will not be in your library, so a wide net is cast. Raising this finds more matches but makes more requests.
How long a built list is kept before it is fetched again.
Rank limits
Only show titles in the top N positions of TMDb's trending list. Position is 1-based: 50 keeps ranks 1–50 and drops anything lower. Leave 0 for no limit.
Only show titles in the top N positions of TMDb's top rated list. Leave 0 for no limit.
Snapshot sources
Ranked lists from IMDb, Netflix, Letterboxd and Rotten Tomatoes, refreshed daily. Leave a URL empty to use the built-in default. Scraping is a last-resort fallback and is off by default.
Display options
Include titles from the ranked source that are not in your library, shown as dimmed "Coming soon" tiles. This is the server default; users can still hide them per view without changing it.
The most missing titles to show per ranked view, across all sources. 0 disables them.
